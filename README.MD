🧬 Cancer Risk Prediction System

An AI-powered healthcare analytics application that predicts cancer risk using Machine Learning and provides real-time clinical insights through an interactive Streamlit dashboard.

✨ Features
• Data Preprocessing & Feature Engineering
• Logistic Regression-based Prediction Model
• Real-time Cancer Risk Assessment
• AI Confidence Scoring
• Clinical Severity Analysis
• Interactive Streamlit Dashboard
• Patient Summary & Recommendations

🛠 Tech Stack
• Python
• Pandas
• NumPy
• Scikit-Learn
• Streamlit
• Joblib

📊 Model Performance
• Accuracy: 89%
• F1 Score: 97%

🚀 Deployment
The application allows users to input patient information and receive instant AI-driven risk predictions with visual analytics and decision-support insights.
